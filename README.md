# RASR-Net
RASR-Net: Deep learning for fast shallow S-wave velocity inversion from P-Wave polarization apparent velocity curves. A residual attention network that directly maps apparent velocity curves to high-resolution shallow S-wave velocity structures. Designed for continental basins. Provides rapid initial models for full-waveform inversion.
This repository primarily includes the model architecture, training scripts, evaluation code, and the dataset used in this study.
